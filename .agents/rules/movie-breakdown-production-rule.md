# Movie Breakdown Production Rule

For every Movie Breakdown video-production task:

1. Read `MOVIE_BREAKDOWN_MASTER.md` before beginning production.
2. Follow the master prompt's 14 sections and quality standards.
3. Use the existing Remotion project architecture.
4. Never overwrite existing video compositions, assets or rendered videos.
5. Create isolated assets and a separate composition for every new video.
6. Never modify an approved script without explicit permission.
7. Complete research, visual decision planning and storyboard before editing.
8. Perform actual render inspection and technical validation before declaring completion.
9. Do not claim any task, verification, render or QC was completed unless it actually was.
10. When the user supplies a movie title, topic and approved script, begin the production workflow without asking them to paste the master prompt again.

The master prompt file is the authoritative production standard.
